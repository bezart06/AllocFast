# Security Policy

Thank you for taking the time to report a security vulnerability. As a custom memory allocator, ensuring memory safety and preventing vulnerabilities is highly important to us.

## Supported Versions

Currently, only the `main` branch is actively supported with security updates. 

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0 (or any other)   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them directly to the maintainer by emailing **bezart06@gmail.com**.

Please include the following information in your report:
*   A description of the vulnerability.
*   Steps to reproduce the issue (a minimal reproducible example in C is highly appreciated).
*   The potential impact of the vulnerability.

You should receive a response within 48 hours acknowledging receipt of your email. We will keep you updated as we investigate and develop a patch. Once the issue is resolved, we will publish a security advisory and credit you for the discovery (unless you prefer to remain anonymous).
